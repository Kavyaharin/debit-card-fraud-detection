# Debit Card Fraud Detection – Fraud Watch

## Project Overview
An AI-based debit card fraud detection project using Machine Learning.

## Technology Stack
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Streamlit

## Features
- Analyse transaction details.
- Predict potential fraudulent transactions.
- Display fraud probability.

## Model
Logistic Regression with preprocessing using StandardScaler and OneHotEncoder.

## Disclaimer
This is an educational project using a synthetic dataset.
It is not intended for production banking decisions.
